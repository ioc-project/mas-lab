# mas-lab-demo-ui-replay(1)

## NAME

`mas-lab demo-ui replay` — Alias of `mas-lab replay`

## SYNOPSIS

```text
mas-lab demo-ui replay [OPTIONS] TARGET
```

## DESCRIPTION

Same as [`mas-lab replay`](replay.md): ingest native `events.jsonl` or a
ui-trace into the live dashboard.

## OPTIONS

See `mas-lab demo-ui replay --help` for the current flag list (Click help is the source of truth).
