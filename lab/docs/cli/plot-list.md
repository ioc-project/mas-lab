# mas-lab-plot-list(1)

## NAME

`mas-lab plot list` — Discover generated plot artefacts

## SYNOPSIS

```text
mas-lab plot list [OPTIONS]
```

## DESCRIPTION

Discover generated plot artefacts.

## OPTIONS

| Flag | Meaning |
|------|------|
| `DIR` | Positional argument. |
| `--traces` | Also list events.jsonl trace files. |
