# mas-lab-demo-ui(1)

## NAME

`mas-lab demo-ui` — Offline live-dashboard export (same plugins, no backend)

## SYNOPSIS

```text
mas-lab demo-ui [OPTIONS] COMMAND [ARGS]...
```

## DESCRIPTION

Offline live-dashboard export. Writes a static site from native events or a
ui-trace; does not start the controller HTTP API.

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.

## SEE ALSO

- `mas-lab demo-ui export`
- `mas-lab demo-ui replay`
- `mas-lab replay`
- `mas-lab serve`
