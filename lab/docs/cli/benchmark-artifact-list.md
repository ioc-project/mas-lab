# mas-lab-benchmark-artifact-list(1)

## NAME

`mas-lab benchmark artifact list` — List artifacts for a run

## SYNOPSIS

```text
mas-lab benchmark artifact list [OPTIONS]
```

## DESCRIPTION

List artifacts for a run.

## OPTIONS

| Flag | Meaning |
|------|------|
| `TARGET` | Positional argument. |
| `-t`, `--type` | Filter by artifact type. |
| `-l`, `--level` | Filter to one hierarchy level. |
| `-v`, `--verbose` | Include the type description. |
