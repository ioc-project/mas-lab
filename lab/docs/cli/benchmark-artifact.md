# mas-lab-benchmark-artifact(1)

## NAME

`mas-lab benchmark artifact` — List and show experiment artifacts

## SYNOPSIS

```text
mas-lab benchmark artifact [OPTIONS]
```

## DESCRIPTION

List and show experiment artifacts.

## COMMANDS

| Command | Page |
|---------|------|
| `list` | [artifact list](benchmark-artifact-list.md) |
| `show` | [artifact show](benchmark-artifact-show.md) |

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.
