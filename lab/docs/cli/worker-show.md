# mas-lab-worker-show(1)

## NAME

`mas-lab worker show` — Show one worker

## SYNOPSIS

```text
mas-lab worker show [OPTIONS]
```

## DESCRIPTION

Show one worker.

## OPTIONS

| Flag | Meaning |
|------|------|
| `WORKER_ID` | Positional argument. |
