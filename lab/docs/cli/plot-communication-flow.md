# mas-lab-plot-communication-flow(1)

## NAME

`mas-lab plot communication-flow` — Agent-to-agent routing graph

## SYNOPSIS

```text
mas-lab plot communication-flow [OPTIONS]
```

## DESCRIPTION

Agent-to-agent routing graph.

## OPTIONS

| Flag | Meaning |
|------|------|
| `SOURCE` | Positional argument. |
| `--format` | Output format. |
| `--title` | Diagram title. |
| `--output`, `-o` | Write output to FILE (default: <source-dir>/communication-flow.<ext>). |
