# mas-lab-worker-cancel(1)

## NAME

`mas-lab worker cancel` — Cancel a worker

## SYNOPSIS

```text
mas-lab worker cancel [OPTIONS]
```

## DESCRIPTION

Cancel a worker.

## OPTIONS

| Flag | Meaning |
|------|------|
| `WORKER_ID` | Positional argument. |
