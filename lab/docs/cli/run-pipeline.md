## NAME

`mas-lab run pipeline` — Pipeline steps without a full benchmark

## SYNOPSIS

```text
mas-lab run pipeline [OPTIONS]
```

## DESCRIPTION

Pipeline steps without a full benchmark.

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.
