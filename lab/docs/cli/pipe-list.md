# mas-lab-pipe-list(1)

## NAME

`mas-lab pipe list` — List registered processor elements

## SYNOPSIS

```text
mas-lab pipe list [OPTIONS]
```

## DESCRIPTION

List registered processor elements.

## OPTIONS

| Flag | Meaning |
|------|------|
| `--import` | Import a Python module to register additional processors. |
