# mas-lab-worker-follow(1)

## NAME

`mas-lab worker follow` — Follow worker output

## SYNOPSIS

```text
mas-lab worker follow [OPTIONS]
```

## DESCRIPTION

Follow worker output.

## OPTIONS

| Flag | Meaning |
|------|------|
| `WORKER_ID` | Positional argument. |
| `--interval` | Poll interval in seconds (REST poll, same as blocking benchmark run). |
