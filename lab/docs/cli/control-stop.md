# mas-lab-control-stop(1)

## NAME

`mas-lab control stop` — Stop the controller daemon

## SYNOPSIS

```text
mas-lab control stop [OPTIONS]
```

## DESCRIPTION

Stop the controller daemon.

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.
