# mas-lab-benchmark-step-info(1)

## NAME

`mas-lab benchmark step-info` — Show registered pipeline step types

## SYNOPSIS

```text
mas-lab benchmark step-info [OPTIONS]
```

## DESCRIPTION

Show registered pipeline step types.

## OPTIONS

| Flag | Meaning |
|------|------|
| `STEP_TYPE` | Positional argument. |
| `--json-output` | Output as JSON. |
