# mas-lab-benchmark-daemon-stop(1)

## NAME

`mas-lab benchmark daemon stop` — Stop the UI daemon

## SYNOPSIS

```text
mas-lab benchmark daemon stop [OPTIONS]
```

## DESCRIPTION

Stop the UI daemon.

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.
