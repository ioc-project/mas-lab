# mas-lab-run(1)

## NAME

`mas-lab run` — Run processors and pipeline steps

## SYNOPSIS

```text
mas-lab run [OPTIONS]
```

## DESCRIPTION

Run processors and pipeline steps.

## OPTIONS

This command takes no extra flags. See `--help` for inherited group options.

## SEE ALSO

- `mas-lab run processor`
- `mas-lab run pipeline`
- `mas-lab run pipeline step`
- `mas-lab --help`
