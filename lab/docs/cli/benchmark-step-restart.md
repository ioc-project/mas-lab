# mas-lab-benchmark-step-restart(1)

## NAME

`mas-lab benchmark step restart` — Restart one step

## SYNOPSIS

```text
mas-lab benchmark step restart [OPTIONS]
```

## DESCRIPTION

Restart one step.

## OPTIONS

| Flag | Meaning |
|------|------|
| `BENCHMARK_ID` | Positional argument. |
| `STEP_ID` | Positional argument. |
| `-o`, `--output-dir` | — |
