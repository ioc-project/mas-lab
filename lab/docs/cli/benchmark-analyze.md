# mas-lab-benchmark-analyze(1)

## NAME

`mas-lab benchmark analyze` — Regenerate plots from existing output

## SYNOPSIS

```text
mas-lab benchmark analyze [OPTIONS]
```

## DESCRIPTION

Regenerate plots from existing output.

## OPTIONS

| Flag | Meaning |
|------|------|
| `BENCHMARK_ID` | Positional argument. |
| `--experiment-yaml` | Path to experiment.yaml (auto-detected if omitted). |
| `-o`, `--output-dir` | — |
