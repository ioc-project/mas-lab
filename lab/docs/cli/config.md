# mas-lab-config(1)

## NAME

`mas-lab config` — Print resolved data and cache paths

## SYNOPSIS

```text
mas-lab config [OPTIONS]
```

## DESCRIPTION

Print resolved data and cache paths.

## OPTIONS

| Flag | Meaning |
|------|------|
| `--json` | Output as JSON instead of human-readable text. |
