# mas-lab-benchmark-artifact-show(1)

## NAME

`mas-lab benchmark artifact show` — Show one artifact by id

## SYNOPSIS

```text
mas-lab benchmark artifact show ARTIFACT_ID
```

## DESCRIPTION

Print one generated artifact identified by its 8-character id.

## OPTIONS

| Flag | Meaning |
|------|------|
| `ARTIFACT_ID` | Positional argument. |

## SEE ALSO

- `mas-lab benchmark artifact`
- `mas-lab benchmark artifact list`
- `mas-lab benchmark show`
