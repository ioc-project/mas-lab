# mas-lab-serve(1)

## NAME

`mas-lab serve` — Start the benchmark UI server

## SYNOPSIS

```text
mas-lab serve [OPTIONS]
```

## DESCRIPTION

Start the benchmark UI server.

## OPTIONS

| Flag | Meaning |
|------|------|
| `--port`, `-p` | TCP port for the controller HTTP API. |
