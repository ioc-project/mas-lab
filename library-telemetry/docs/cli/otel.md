# mas-lab-otel(1)

## NAME

`mas-lab otel` — Alias of mas-lab telemetry

## SYNOPSIS

```text
mas-lab otel [COMMAND] [ARGS]...
```

## DESCRIPTION

`mas-lab otel` is registered as an alias of `mas-lab telemetry` when
library-telemetry is installed. Use the telemetry man pages for flags and
subcommands.

## OPTIONS

This group takes the same commands as `mas-lab telemetry`.
