# mas-lab-telemetry-kinds(1)

## NAME

`mas-lab telemetry kinds` — List native event kinds with a span handler

## SYNOPSIS

```text
mas-lab telemetry kinds [OPTIONS]
```

## DESCRIPTION

List native event kinds that have a registered span handler.

## OPTIONS

See `mas-lab telemetry kinds --help` for the current flag list (Click help is the source of truth).
