# mas-lab-telemetry-inspect(1)

## NAME

`mas-lab telemetry inspect` — Span-file summary without validation

## SYNOPSIS

```text
mas-lab telemetry inspect [OPTIONS]
```

## DESCRIPTION

Print span / trace / boundary counts. Inspection only — no pipeline YAML.

## OPTIONS

See `mas-lab telemetry inspect --help` for the current flag list (Click help is the source of truth).
