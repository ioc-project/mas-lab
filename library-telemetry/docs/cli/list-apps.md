# mas-lab-telemetry-list-apps(1)

## NAME

`mas-lab telemetry list-apps` — List apps in ClickHouse otel_traces

## SYNOPSIS

```text
mas-lab telemetry list-apps [OPTIONS]
```

## DESCRIPTION

List `ServiceName` values in ClickHouse `otel_traces`.

See `mas-lab telemetry list-apps --help` for the current flag list (Click help is the source of truth).
