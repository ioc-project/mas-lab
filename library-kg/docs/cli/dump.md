# mas-lab-kg-dump(1)

## NAME

`mas-lab kg dump` — Deserialize a KG from Neo4j

## SYNOPSIS

```text
mas-lab kg dump [OPTIONS]
```

## DESCRIPTION

Read a session or run KG back from Neo4j. Same `neo4j_dump` step as `kg:neo4j-dump`.

## OPTIONS

See `mas-lab kg dump --help` for the current flag list (Click help is the source of truth).

## PIPELINE

`kg:neo4j-dump`
