# mas-lab-kg-push(1)

## NAME

`mas-lab kg push` — Serialize a KG to Neo4j

## SYNOPSIS

```text
mas-lab kg push [OPTIONS]
```

## DESCRIPTION

Serialize a KG document to Neo4j. Alias: `neo4j-push`. Same `neo4j_push` step as `kg:native-to-neo4j`.

## OPTIONS

See `mas-lab kg push --help` for the current flag list (Click help is the source of truth).

## PIPELINE

`kg:native-to-neo4j`
